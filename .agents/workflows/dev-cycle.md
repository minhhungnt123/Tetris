description: Quy trình phát triển tính năng Game 3D toàn diện cho đồ án tốt nghiệp robot.
---

Mỗi khi tôi yêu cầu một tính năng mới cho robot, hãy thực hiện nghiêm ngặt theo các bước sau:

1. **Phân tích**: Xác định các thành phần vật lý và logic cần thiết trong Unity (Rigidbody, Collider, Joints).
2. **Lập kế hoạch**: Liệt kê các file script cần tạo trong folder `_Scripts` và cấu trúc sơ bộ của chúng.
3. **Thiết kế**: Viết code C# hoàn chỉnh. Đảm bảo Clean Code, đặt tên theo chuẩn PascalCase và chú thích rõ ràng bằng tiếng Việt.
4. **Hướng dẫn Setup**: Chỉ dẫn chi tiết các bước thao tác trên Unity Editor để tích hợp code và model 3D từ folder `_Models`.
5. **Cải thiện & So sánh**: Tự đánh giá lại code so với yêu cầu ban đầu, đề xuất cách tối ưu hiệu năng vật lý.

Cuối cùng, luôn kết thúc bằng một câu hỏi định hướng để tôi biết cần làm gì tiếp theo.
